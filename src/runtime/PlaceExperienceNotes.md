# Place experience contract

A selected place must expose one compact primary action surface: Navigate, Add to Route, Details.

Identity is shared across map pin, result card, popup, and details. Prefer owner/business logo or approved place image; fall back to a category/location icon.

Status vocabulary is explicit: verified, open, premium, community-reported, unknown. Unknown is a deliberate legend state, never an unexplained gray marker.

Details should prioritize: featured owner photo, open/access status, freshness/trust, reviews, community photos, amenities, and only then active offers/promotions/contests/campaigns/quests that have live data.

The consumer map acceptance criterion is bathroom discovery in two clicks: open map, select a bathroom, then act from the selected-place card.
