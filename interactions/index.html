Interaction Engine

QR, geofencing and check-ins are one event-producing layer.

QR / GPS → verified arrival → check-in → geofence event → Quest → rating/evidence → progression → reward → leaderboard → intelligence → notification

QR

Identify, attribute, validate, redeem, start quests and trigger campaigns.

Geofence

Arrival, dwell and exit events can trigger contextual actions and Quest steps.

Check-in

QR, GPS and map check-ins converge on canonical verified activity.

Downstream

Canonical events feed progression, rewards, leaderboards, notifications and intelligence.
