# Ingestion expansion plan

## Priority geography
1. Chicago
2. Chicago metro and adjacent communities
3. Corridors connecting Chicago, St. Louis, and Kansas City
4. Remaining gaps between those markets

## Operating rule
Interactive map discovery must not be treated as canonical ingestion. Scheduled/provider ingestion populates the canonical location dataset, preserves source provenance, and feeds freshness/trust calculations.

## Acceptance
New ingestion coverage should be observable through canonical locations, retain provider/source identity, avoid duplicates, and become available to amenity-first map search without requiring a user to discover the location first.
